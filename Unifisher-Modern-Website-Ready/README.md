# Unifisher Farming — modern website package

This is a clean, responsive Jekyll/GitHub Pages website package designed from the supplied Unifisher Farming website print and conversation.

## Included
- Root-level `index.html` and `_config.yml` (not nested inside another folder)
- Responsive desktop/mobile design
- Product cards for Oyster, Paddy Straw, and Button Mushrooms
- About/story and Why Choose Us sections
- WhatsApp enquiry links and contact form that prepares a WhatsApp message
- `CNAME` for `unifisher.com`
- No custom Jekyll plugins and no Liquid sorting loop, avoiding the previous recipe sort build error

## Before uploading
1. Download and keep a backup of your existing repository files and recipe content.
2. Extract this ZIP on your Windows laptop.
3. The extracted folder should contain `index.html`, `_config.yml`, `CNAME`, `assets/`, `404.html`, and this README directly at the top level.
4. Upload the *contents* of the extracted folder to the repository root, not the containing folder itself.
5. Confirm GitHub Pages is configured to deploy from the branch/root you upload to. If you use a custom Actions workflow, retain or configure that workflow as appropriate.
6. Do not delete branches just to deploy this website. Branch deletion is unrelated to the Jekyll root-folder issue. Keep a backup before replacing files.
